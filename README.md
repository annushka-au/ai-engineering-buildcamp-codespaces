# ai-engineering-buildcamp-codespaces

Code for AI Engineering Build Camp.

## Setup

Install the OpenAI Python package once when setting up the project:

```bash
uv add openai
```

## Run Jupyter Notebook

Each time you start working with the notebooks, run:

```bash
uv run jupyter notebook
```

Jupyter will start locally and provide an address such as:

```text
http://localhost:8888
```

Open this address in your browser to access the notebooks.
